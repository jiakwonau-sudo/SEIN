# SEIN CRUD Sandbox v1.7.0

서버 없이 브라우저에서 실행되는 공유용 CRUD 더미 앱입니다.

## 실행

1. ZIP 압축을 풉니다.
2. `index.html`을 브라우저에서 엽니다.
3. 고객, 상품, 영업, 견적, 회계, 일정, 세금계산서, 자료, 태그 메뉴에서 추가/수정/삭제를 테스트합니다.

## 데이터 저장

- 저장소: 브라우저 `localStorage`
- 키: `sein_crud_sandbox_v170`
- 서버/DB 설치 불필요
- 각 브라우저와 기기마다 데이터가 독립적으로 저장됩니다.

## 공유 방법

### 1. 웹 링크 공유
GitHub Pages 배포 URL을 전달합니다. 각 사용자는 자신의 브라우저에서 독립적으로 CRUD를 테스트합니다.

### 2. 같은 데이터 상태 공유
`데이터 / 설정` 메뉴에서 JSON을 내보냅니다. 상대방이 JSON을 가져오면 동일한 더미 상태를 재현할 수 있습니다.

### 3. 오프라인 전달
이 폴더 전체를 ZIP으로 전달합니다. 별도 서버 없이 `index.html`로 실행됩니다.

## 포함 기능

- Create / Read / Update / Delete
- 검색
- 대시보드 실시간 집계
- CRUD 변경 로그
- JSON 내보내기 / 가져오기
- 기본 더미 데이터 초기화
- 모바일 반응형 UI
- 자체 테스트: `index.html?selftest=1`

## 주의

이 버전은 데모/QA용입니다. 인증, 동시 사용자, 중앙 DB, 권한 통제, 감사로그 무결성은 제공하지 않습니다. 실제 운영용으로 전환할 때는 서버와 인증 계층이 필요합니다.
